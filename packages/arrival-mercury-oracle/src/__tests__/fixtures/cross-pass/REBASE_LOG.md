## goldenEpoch 2 — E2 lands: the hybrid tree's hard side (2026-07-16)

**Four of eight rows changed, in the `residual` column only** — `filter-truthy-zero`,
`multi-list-map`, `apply-plus`, `member-assoc`. Full account (the substrate,
the fold rule, the safety gate) lives in `../gate3/REBASE_LOG.md`'s own
goldenEpoch-3 entry for this same landing — not re-specified here, per this
log's role as `fixtures/gate3/REBASE_LOG.md`'s sibling (this file's own
header note: "different owner, different pipeline slice, no collision").

call to a literal-array chunk-expression whenever every argument is
"call-free" (`isCallFree`); `filter-truthy-zero`'s `list(0, 1, #f)` and
`multi-list-map`/`apply-plus`'s fully-literal `list` calls fold outright,
`member-assoc`'s NESTED `list` calls (`list(1, 2, 3)`, `list(1, "a")`,
`list(2, "b")`) fold too, while its OUTER `list(member(…), assoc(…))` does
NOT (both operands are real `Call`s) — the same mixed outcome
`gate3`'s own log documents in more depth.

**Only the `residual` field moved in all four** — `virtualTs` (a DIFFERENT
pipeline stage, typefacts' own virtual-TS emission, untouched by this
landing) and `facts` are byte-identical, confirming this column really is
independent of the fold decision, as the fixture's own three-column design
intends.

Regenerated by running the exact `extractFacts` → `walk` → `render` slice

four representative rows — contain no `list` call and are confirmed

assumed from the four known cases).
