> Редакционный черновик. Требует подготовки и проверки примеров перед публикацией.

## Задача страницы

Помочь понять, подходит ли Arrival для задачи.

## План содержания

- Три пользовательские ценности: tolerance и исправление ошибок; provenance; uneval.
- Основной сценарий: модель пишет программу, которая комбинирует инструменты и преобразует результаты.
- Роль хоста: capabilities, данные, разрешения и жизненный цикл.
- Сравнение задач с SCI, Starlark и обычными JSON tool calls. Не заявлять уникальность отдельных механизмов или неподтверждённое превосходство.
- Границы: подмножество R7RS, ограничения IO и мутации, версия 0.x.

## Пример для подготовки

Сравнить один рабочий процесс при отдельных вызовах инструментов и при композиции внутри программы, без выдуманных чисел экономии.
