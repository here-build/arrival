> Редакционный черновик. Требует подготовки и проверки примеров перед публикацией.

## Задача страницы

Предоставлять агенту нужную информацию в нужном объёме.

## План содержания

- Короткая agent card для постоянной инструкции.
- Живой каталог реально доступных возможностей конкретного запуска.
- Текстовый справочник для загрузки по необходимости.
- Примеры распространённых задач и исправления ошибок.
- Стабильные URL и Markdown-представление страниц.
- Не отправлять архитектурные принципы как системную инструкцию по языку.

## Пример для подготовки

Показать три отдельных артефакта: card, environment description и ответ справочника на вопрос о функции.
