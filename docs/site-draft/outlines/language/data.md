> Редакционный черновик. Требует подготовки и проверки примеров перед публикацией.

## Задача страницы

Научить преобразовывать результаты инструментов внутри программы.

## План содержания

- Доступ к полям и отсутствующие ключи.
- map, filter, группировка, frequencies, сортировка и выборка.
- Порядок аргументов и различия контейнеров.
- Неизменяемое обновление вложенных данных.
- Точные числа: возможности и пределы; переход в JS.

## Пример для подготовки

Один набор записей: фильтр, подсчёт по категориям, выбор полей и итоговая сводка. Проверить каждый используемый символ.
